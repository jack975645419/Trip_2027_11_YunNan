11/18 腾冲驼峰 TCG → 和顺古镇

  • TCG 在腾冲市区南 12 km
  • 机场大巴：班次稀少（每天 2–3 班），到腾冲市区
  • 网约车 / 包车：推荐；约 ¥30–50、20 min 直达酒店

首推：提前预约接送 / 包车。

11/21 保山云瑞 BSD → 保山酒店（暂短停留）

  • BSD 在保山市区东南 5 km
  • 出租车 / 网约车：约 ¥15–25、15 min 直达酒店

二、城际交通

11/17 → 11/18：广州 CAN → 昆明 KMG（去程）

  • 航班：MU5732 东航
  • 时间：11:20 → 13:55（2h35m）
  • 广州白云 T3 起飞

11/18 → 11/18：昆明 KMG → 腾冲 TCG（转场）

  • 航班：8L9951 祥鹏
  • 时间：13:35 → 14:50（1h15m）
  • 缓冲：落地 TCG 后转酒店（网约车 20 min）

四、腾冲市内（11/19 / 11/20）

11/19：和顺古镇 + 热海

  • 和顺古镇 → 热海：距离约 6 km，建议包车 1 天（¥300–500）
  • 或：和顺古镇 11 号公交 → 腾冲市区 → 转热海公交（班次少）

11/20：火山 + 北海湿地 + 银杏村

  • 3 个点都在城外：

    • - 火山公园：市区北 25 km - 北海湿地：市区北 18 km - 银杏村：市区北 35 km

  • 必须包车 1 天：¥400–600 / 8h
  • 提前 1 周预约

五、注意事项

1. 时差 / 气候：云南用北京时间（UTC+8）；11 月底昼夜温差 10°C——白天短袖 + 早晚厚外套 2. 紫外线：11 月紫外线仍强，必带防晒霜 + 墨镜 3. 高原反应：昆明海拔 1892 m、腾冲 1640 m、保山 1670 m，对多数人无影响，避免剧烈运动 4. 网络：山区信号一般，提前下载离线地图（高德 / 百度） 5. 支付：云南几乎全支持微信 / 支付宝；景区门票部分需现场购票（部分支持电子票） 6. 酒店预订：建议出发前 2 周订完（11 月下旬银杏季是旺季） 7. 航班改动：3 段航班都是直飞，无中转风险；但腾冲驼峰小机场遇大雾可能备降昆明，留 1 天缓冲（如机票允许）
